# ZigZag 0.1.1

Faster editing and stitch planning, more reliable copy/paste and embroidery
exports, and a Windows download built with GitHub Actions.

## Improvements and fixes

- Open SVGs without text faster by skipping the system font scan; scan fonts
  in the background in the editor.
- Speed up large selections, deleting objects, saving, overlap removal,
  stitch checks, and stitch playback. Reduce redraws while the editor is idle.
- Fix copy/paste, including duplicate paste events on Windows, and preserve
  names and stitch settings when adding the same artwork more than once.
- Preserve stitch positions when re-exporting imported embroidery files;
  improve handling of malformed PES, JEF, and Bluetooth capture files.
- Make stitch-type changes and object reordering undoable, and improve
  planning before exports, Bluetooth uploads, and agent requests.
- Fix edge cases in satin stitching, routing, SVG references, MCP batches,
  and MCP bridge responses.

## Install on Mac

Download **ZigZag.dmg**, open it, and drag **ZigZag** into **Applications**.
Requires macOS 11 or later; one download supports Apple Silicon and Intel.

`ZigZag-0.1.1.dmg` is the same download with the version in its filename.
`SHA256SUMS.txt` contains checksums for both filenames.

## Install on Windows

Download **ZigZag-0.1.1-x86_64-windows.zip**, unzip it, and open **ZigZag.exe**.
Requires 64-bit Windows 10 (version 1709 or later) or Windows 11.
The Windows download is built by GitHub Actions and is unsigned; if SmartScreen
blocks it, choose **More info** → **Run anyway**.

The archive includes the editor, **zigzag-cli.exe** command-line tool, and
**zigzag-mcp.exe** MCP bridge. No Rust installation or Visual C++
redistributable is needed. `SHA256SUMS-windows.txt` contains its checksum.
